# AI4BrCa

面向医院专家的乳腺癌临床研究候选入组与 AI 生活化患教合作方案。

## 内容

- `index.html`：GitHub Pages 网页版方案
- `docs/殷咏梅教授_临床研究筛选合作方案_医院专家版.pptx`：整合深至公司相关能力的医院专家沟通版 PPTX
- `assets/senz-logo.png`：方案使用的 senz 深至科技标识

## 产品主线

1. 入院端拍病历，识别病理、分期、治疗线次和关键指标，展示候选研究及证据状态。
2. 出院端按乳腺癌治疗阶段提供生活化、互动式患教，支持症状记录和人工升级。
3. 结合深至 Dx 医生端、Cx 患者端与真实世界研究能力，形成医院可复核的合作闭环。

网页内容仅用于合作讨论，不构成医疗建议或正式研究入组决定。

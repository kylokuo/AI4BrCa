现有筛选痛点

人工初筛的瓶颈并非单一检索，而是跨系统、跨时间、跨证据的反复核对。

入排标准复杂年龄、分期、分子分型、既往线次、洗脱期、器官功能等条件组合多，且常有AND/OR/例外条款。
数据散落在多处病理、检验、影像、用药、既往治疗和病程记录分布在不同页面或不同系统。
研究护士依赖人工摘录需要反复翻阅病历、复制结果、回到方案核对，工作节奏容易被高峰入院打断。
待确认项难以聚焦部分条件不是“不符合”，而是当前证据不足；人工常把“未找到”误当成“没有”。
候选漏筛与重复筛选同一患者可能被不同人重复筛选，研究开放状态、筛选状态又不能及时同步。
PI复核缺少证据链最终确认往往只能看到结论，不能快速定位到原始病历、检验或病理依据。
DESIGN PRIORITY
先把“找人”变成“找证据”

系统的第一输出不是一个分数，而是一张可复核的条件矩阵：每条入排标准对应患者证据、证据时间、来源位置和当前状态。

原则：模型可以加速初筛，最终入组仍由研究护士与PI确认。

临床研究筛选主流程

入院模式作为主路径，出院模式负责补齐随访与研究数据回流。

01 / 拍
拍病历病理、入院记录、检验单、用药单和既往治疗材料。
02 / 识别
AI抽取识别分型、分期、线次、时间窗和关键实验室指标。
03 / 显示
候选入组展示候选研究及符合、不符合、待确认状态。
04 / 核验
证据核验逐条定位原始证据，处理缺失、冲突和过期信息。
05 / 复核
护士 / PI确认确认是否进入知情、筛查检查或排除记录。
06 / 回流
患教与研究出院后的互动患教和随访数据回到研究库。

效率提升的工作方式

评价重点应放在“复核负担下降”和“证据链完整”，而不是单纯追求自动化率。

现行人工模式

  • 从患者列表开始逐个翻阅病历
  • 在病理、检验、用药页面之间切换
  • 把信息摘录到个人表格或研究文件
  • 遇到不确定项再回头问医生或PI
  • 筛选结果难以复用，也难以追溯版本

AI协作模式

  • 入院触发患者与开放研究的候选匹配
  • 按入排标准生成条件矩阵
  • 每项结果带证据位置与时间戳
  • 优先处理待确认项与高风险排除项
  • 护士确认、PI复核、过程日志完整留存

AI患教：从知识问答到生活化互动

出院模式先不追求复杂管理，重点是让患者每天得到一小步、一个可记录项和清晰的升级路径。

今天做什么按治疗阶段给出散步、休息、饮食和情绪照护的小任务，避免一上来讲大段知识。
我要记录什么用症状卡、用药卡和PRO记录治疗体验，形成可带给医护的摘要。
生活场景问答围绕工作、睡眠、身体形象、亲密关系和家人沟通进行互动式患教。
何时联系医护识别高风险症状和持续变化，提供护士/医生升级入口，不自动下诊疗结论。
BOUNDARY

高风险问题必须升级人工

持续高热、严重不良反应、病情快速变化、治疗停药或患者强烈焦虑等情况，AI只负责识别与提醒，不自动给出诊疗指令。

互动式患教的最小闭环

患者选择阶段刚确诊、手术前后、系统治疗中、复查与长期管理、晚期长期共存。
AI用生活语言回应先问清治疗阶段和限制，再给一小步可执行行动。
患者反馈与升级患者勾选完成、补充症状，或一键转给护士/医生。

把一次筛选工具，做成可持续产生研究问题和队列的临床数据入口。

首期实施与验收

以一个病区、1–2个在招研究和一条入院流程起步，先验证价值再扩大范围。

0–4周 / 定义梳理病区流程、研究方案、数据字段、责任边界和禁止事项。
5–8周 / 原型完成研究知识库、患者摘要和逐条核验原型。
9–12周 / 回放用历史病例做离线回放，建立错误案例库并由临床团队审阅。
13–18周 / 静默不影响临床决策地观察前瞻筛选，比较人工与AI协作耗时。
19–24周 / 受控上线在明确的医护复核与审计机制下扩展到稳定使用。
